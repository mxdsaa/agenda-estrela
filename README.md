# Agenda Estrela

App (PWA) para montar a Frente e o Verso das folhas A5 da agenda, escolher o ano e baixar o PDF.
Feito para a Estrela de Maria. Tudo roda no navegador; nada é enviado para servidor.

Editor no estilo Canva: barra de baixo (Modelos, Elementos, Texto, Mídia, Fundo, Agenda, Camadas),
barra de ferramentas do item selecionado, guias de alinhamento, seleção múltipla, grupos, bloqueio,
edição de texto direto na folha e 11 modelos prontos.
Uma folha só vale para todas as páginas; Frente e Verso diferentes é opção avançada (Modelos › Avançado).
Painel Elementos com busca em português, Recentes, categorias e troca de cor por parte.

Abrir: https://mxdsaa.github.io/agenda-estrela/
